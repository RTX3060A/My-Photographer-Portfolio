# DAVID SPACE 高级摄影作品集升级计划

目标：从"个人简单作品集"升级为品牌级、完整的摄影作品网站，重点是作品观看体验与拍摄档案（地点、器材、参数）。

## 1. 全新作品观看器（核心）
- 全屏沉浸式观看：黑色/白色背景可切换，图片居中自适应。
- 缩放：鼠标滚轮 / 双击 / 双指捏合放大，放大后可拖动平移，一键还原；显示缩放比例（如 100%、200%）。
- 浏览：左右方向键、点击两侧、手机左右滑动切换；底部缩略图条可快速跳转；显示"3 / 20"。
- 信息面板（按 I 键或按钮展开，侧边滑出）：
  - 作品标题、系列、年份、客户
  - 拍摄地点（城市、国家、经纬度）+ 小地图定位
  - 器材与参数：相机、镜头、焦距、光圈、快门、ISO
  - 摄影师 / 团队署名、作品描述
- 工具栏：全屏、幻灯片自动播放、分享链接（每张作品有独立网址，可直接分享打开）、隐藏界面（纯看图模式）。
- 键盘快捷键提示（按 ? 显示）。

## 2. 作品档案与地图
- 新增"地图"页面：世界地图上标出所有拍摄地点，点击标记查看该地作品。
- 新增"系列"页面：按项目/系列展示（封面 + 简介 + 作品数 + 地点 + 年份），点击进入系列详情。
- 系列详情页：大图叙事式排版，配拍摄档案信息条。

## 3. 首页与整体界面升级
- 首页开场：全屏精选作品轮播 + DAVID SPACE 品牌字标。
- 作品墙：分类筛选（精选/商业/编辑/个人）、地点筛选、排序；悬停显示标题与地点。
- 导航：作品 / 系列 / 地图 / 关于 / 联系，滚动时自动收起。
- 统一高级视觉：编辑杂志风，衬线标题 + 细字体正文，黑白为主，克制动效。

## 4. 内容说明
- 目前作品图片来自网络图库，地点和相机参数会先用示例数据填充，之后可替换为您的真实作品与信息。

## 技术细节
- 新建作品数据文件（id、标题、系列、分类、地点、经纬度、EXIF 参数、图片），图库与观看器统一读取。
- 观看器重写 `Lightbox`：使用 react-zoom-pan-pinch 实现缩放平移；URL 参数 `?photo=id` 支持深链。
- 地图使用 react-leaflet + OpenStreetMap 免费底图（无需密钥）。
- 新路由：`/series`、`/series/:slug`、`/map`；现有 `/category/:category` 保留。
- 设计变量统一写入 index.css 与 tailwind 配置；不重新添加 newsletter。
